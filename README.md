# Sky Whale — coolest-art-01

A colossal blue whale swims through a dusk sky above a neon city, rising
toward a huge pale moon, its spout bursting into glowing droplets.

Pure Python 3 standard library, deterministic: `main.py` draws the whole
1024×1024 image from scratch (sky gradient, stars, moon, skyline, whale)
and writes it to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output`).

Run: `MAKEFUN_OUTPUT_DIR=out python3 main.py`
